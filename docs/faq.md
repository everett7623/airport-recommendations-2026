# 机场常见问题解答

> 技术资料核验：2026-10-13。技术说明不代表本轮节点实测；服务商、套餐与下架信息以 VPSKnow 同步生成的 README 和 `data/airports.json` 为准。

## 机场、协议与客户端是什么关系？

机场提供节点及订阅；协议定义连接方式；内核实现协议与路由；客户端提供导入和操作界面。代理工具也可能通过系统 VPN/TUN 接口接管流量，不能简单按机场比 VPN 更快、更安全选型。实际体验取决于线路、拥塞、配置和服务运营。

参见 [协议与兼容性](protocols.md)与 [客户端教程](client-setup.md)。仅支持专用客户端的服务不保证兼容通用订阅工具。

## 原生 IP 能保证 Netflix 等服务可用吗？

不能。原生 IP、住宅 IP 等标签不保证平台接受该出口；内容还受账号、地区、套餐及平台策略影响。Netflix 官方说明使用 VPN 时可能仅展示全球版权内容，部分方案与功能也有限制，见 [Netflix 帮助](https://help.netflix.com/en/node/114701)。应在自己账号与目标设备上验证，不能由 IP 标签推断全片库。

## AI 或其他应用提示拒绝访问，换节点就能解决吗？

未必。先检查官方服务状态、账号与地区支持情况，再检查网络错误、出口变化及分流是否覆盖登录/API 请求。节点名称中有 AI 或解锁只是服务商标记，不能视为平台保证。

隐私窗口可用于区分浏览器会话问题，但清理 Cookie 不会改变出口 IP 或账号资格。不要将单次拒绝访问直接归因于 IP 信誉。

## TikTok 无内容，是否必须拔 SIM 卡或使用原生 IP？

不应将这些做法作为必需条件。可能涉及账号、商店地区、服务覆盖、应用版本、网络与平台策略；缺乏证据时不能断言某一信号是唯一原因。先检查官方帮助、应用更新与连通性，保留具体错误信息。

## IPLC / IEPL、BGP 标签意味着什么？

IPLC / IEPL 是线路服务术语，机场标签不能证明端到端专线覆盖、带宽保障或实际拓扑；BGP 是路由协议，也不是高速保证。性能需在自己的网络、时间段和应用上验证，不能承诺不过墙、永远稳定或游戏延迟最低。

## 什么是流量倍率？

例如 1x 节点使用 1GB，通常按 1GB 扣除；3x 通常按 3GB 扣除。统计口径、上下行计费与倍率以条款和控制台为准。先确认倍率，再进行大流量测速或下载。

## 月付还是年付？如何降低服务中断风险？

先试用或短周期确认适配，再按需付费；运营时间、价格和宣传均不能保证持续服务。需要备用时选择不同服务并验证套餐与节点可用性，不限时仍受运营状态和条款约束。维护或下架按上游证据同步，不根据一次超时自行修改名单。

## 所有节点超时，怎么排查？

1. 检查套餐、流量与订阅有效性，确认选中了正确配置。
2. 更新订阅，检查导入错误与服务商公告。
3. 校准系统时间，检查本地网络与节点域名解析。
4. 换节点或网络对照；查看防火墙、TUN 与其他 VPN 冲突。
5. 保留客户端、内核版本与脱敏日志，按错误定位；不要直接关闭 TLS 验证。

## 国内网站异常，是全局模式造成的吗？

可能，也可能是规则、DNS、出口、路由冲突或网站故障。先看连接日志的策略命中，再短时对照直连与代理路径；规则模式也可能将某些国内请求送入代理，不能仅靠切换模式判断原因。

## 延迟低为什么下载仍慢？

健康检查测响应延迟，吞吐受带宽、拥塞、服务器与链路影响。分别检查本地直连、目标站点、不同节点和晚高峰表现；自动选择低延迟节点不代表最大带宽。游戏还要关注抖动、UDP 与会话稳定性。

## Fake-IP、加密 DNS、TUN 能保证没有泄露吗？

不能。Fake-IP 是域名映射方式；DoH/DoT 加密到解析器的查询；TUN 按路由接管流量。需要检查实际 DNS 出站路径、应用自带解析器与 IPv6。官方字段与步骤见 [进阶指南](advanced.md)。

## 机场能看到哪些信息？

服务端可观察连接时间、流量、目标 IP 等元数据；域名可见性取决于 DNS、TLS 及配置。HTTPS 在正确验证证书且未遭端点入侵等情况下保护内容，但不隐藏全部元数据，也不能代替对服务商的信任。不安装来源不明的根证书，不将代理等同于匿名或无日志保证。

## 订阅能分享或交给在线转换网站吗？

订阅通常含访问令牌，可用于获取节点凭据。分享前考虑账户权限和服务条款；不把完整 URL 放到公开 Issue、截图、仓库或不可信工具。泄露后重置。优先用原生格式，必要的自托管转换也需检查权限、日志和来源。

## 为什么浏览器能用，Git、IDE、容器却不能？

工具可能不读取系统代理，或运行在不同网络环境。检查各自设置、实际端口和 DNS 路径；Git HTTPS 与 SSH 也使用不同设置。一次性验证见 [进阶指南](advanced.md)，避免永久写入无用全局代理或关闭证书校验。

## 如何判断教程是否过时？

核对客户端与内核版本，查看官方稳定版说明、配置文档及迁移指南；新版本不代表兼容任意旧配置。本项目每月复核技术内容，只对实际核验的说明更新日期；机场数据版本继续来自 VPSKnow，与技术核验日期独立。
